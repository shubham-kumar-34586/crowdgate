# User Stories

User stories describe the software from the perspective of end users.


## US-001

### Title

User Registration

### User Story

As a guest user,

I want to create an account,

so that I can book event tickets.

### Priority

High

### Requirement

FR-001


## US-002

### Title

User Login

### User Story

As a registered user,

I want to log in securely,

so that I can access my bookings and profile.

### Priority

High

### Requirement

FR-002



## US-003

### Title

Browse Events

### User Story

As a user,

I want to browse available events,

so that I can choose an event to attend.

### Priority

High

## US-004

### Title

Book Ticket

### User Story

As a user,

I want to reserve seats,

so that I can attend an event.

### Priority

Critical

## US-005

### Title

Organizer Creates Event

### User Story

As an organizer,

I want to create events,

so that users can purchase tickets.

### Priority

High
